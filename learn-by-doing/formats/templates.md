## LEARNING_MAP.md（能力地图）

```markdown
# Learning Map: {主题}
## 能力维度
- {能力名}: {一句话} → 当前等级: {L0-L4} → 对应项目: {项目名 / 无} → 下一步: {任务 / 无}
## 核心模块
- {模块名}: {一句话} → 前置依赖: {无 / 其他模块}
## 模块关系
{依赖图或文字描述}
```

规则：
- 按"解决工程问题所需能力"组织，不照抄教材目录
- 能力维度区只保留：能力名 / 当前等级 / 对应项目 / 下一步任务。详细知识不放入地图
- 等级使用五级标准：L0 未接触 / L1 能识别 / L2 能借助 AI 修改并验证 / L3 能借助 AI 可靠交付 / L4 能在新约束下迁移
- Python 主题的能力维度直接用 `references/python-skeleton.md` 的十项能力树

## XMind 对比表

> 规则见 `SKILL.md` §教学原则 > 输出格式约定。
> 输出对比表时优先用此格式，不用 markdown 表格。

### 格式规则

- 第一行：标题（根节点）
- 每个选项用 tab 缩进
- 每个属性用双 tab 缩进
- 属性值写在冒号后

### 模板

```
{主题/标题}
	{选项1}
		{属性A}：{值}
		{属性B}：{值}
	{选项2}
		{属性A}：{值}
		{属性B}：{值}
```

### 示例

```
SSL 证书类型对比
	DV（域名验证）
		验证内容：域名归属
		签发速度：实时
		价格：免费（Let's Encrypt 等）
		适用场景：个人博客、小型网站
	OV（组织验证）
		验证内容：企业注册信息
		签发速度：几天
		价格：中等
		适用场景：企业官网
	EV（扩展验证）
		验证内容：严格企业审核
		签发速度：更久
		价格：最贵
		适用场景：金融、电商（浏览器地址栏显示公司名）
```

### 何时用表格 vs XMind

- 命令速查 / 简单键值对 → markdown 表格
- 分类对比 / 多属性比较 / 层级结构 → XMind tab 缩进
- 有嵌套子属性 → 必须用 XMind

### 测试三路径清单

可测试功能按风险选用（见 `SKILL.md` §核心行为纪律 15 证据与风险相称），不机械要求每项全部覆盖：

- [ ] 正常路径：输入合法时行为正确
- [ ] 异常路径：错误输入、网络失败、非法参数等
- [ ] 边界条件：空值、0、最大/最小、超时阈值
- [ ] 独立证据：至少一项不只依赖 AI 同时生成的实现与测试，如业务样例、官方契约、静态检查、基准或人工验收

## 过程文档（康奈尔式）

> 触发词：用户说"总结过程文档"/"记录这节"/"沉淀一下"时使用（不自动输出）。
> 目的：记录"这节该记住什么"和"对话暴露了什么"，不是逐句转录教学输出。

```markdown
> 过程文档 · {YYYY-MM-DD}
> 教学方式：{三层次教学法 / 问答 / 排障引导}
> 交互类型：{问答 / 概念纠正 / 场景题 / 自由讨论}

## 一、知识要点（复习用）

关键链路、核心概念、面试考点、速查表。
只记结论和框架，不记大段解释。
使用 XMind 缩进或 Mermaid 图表达层级/流程。

## 二、交互记录

用户问/说了什么 → 暴露了什么理解偏差 → 我做了什么调整。
记录有价值的对话节点，不是逐句转录。

## 三、薄弱点标记

用户在此节暴露的概念模糊点、错误理解、未覆盖的边界。
用 [ ] 列表标记，下次教学时优先回顾。

## 本节一句话

> 记不住全部时只记这一句。
```
