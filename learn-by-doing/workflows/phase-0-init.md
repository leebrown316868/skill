# Phase 0：初始化

## 触发条件

工作区不存在或 LEARNING_STATE.md 不存在且无 MISSION.md。

## 流程

### 1. 问三个问题

引导用户回答，不要批量化：

1. **学什么？**
   - 哪个技术 / 工具 / 框架
   - 具体版本（如果有）

2. **为什么学？**
   - 工作要用 / 想转方向 / 兴趣 / 解决什么问题
   - Why 越具体，项目设计越精准

3. **当前基础？**
   - 用过类似的吗
   - 听说过多少
   - 之前踩过什么坑

### 2. 确认后进入 Phase 1

用户回答了三个问题后，总结确认：

```
好，我理解你想学 {技术}，因为 {原因}，你当前的基础是 {基础}。
接下来我先初始化资源索引和学习地图。
```

→ 进入 Phase 1

## 退出条件

- [ ] 三个问题已回答
- [ ] 用户确认了学习目标
