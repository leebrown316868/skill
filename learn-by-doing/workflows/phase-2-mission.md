# Phase 2：定项目

## 触发条件

Phase 1 完成。

## 流程

### 1. 基于 LEARNING_MAP.md 设计项目

参考地图中的模块，设计一个**真实项目目标**：

```
项目设计要求：
- 要覆盖 LEARNING_MAP 中的核心模块（至少 M01-M03）
- 要产出真实的可运行产物（不是练习题的堆砌）
- 要在合理时间内可完成（1-3 个会话）
- 要有实用性（做完能用上）
```

### 2. 写成 MISSION.md

按 `formats/MISSION-FORMAT.md` 编写。

**重要：不要替用户写 Why。** 引导用户自己说。

### 3. 引导用户确认

逐条检查验收标准：
- 每条是否可验证？
- 每条是否有具体输出？
- 范围是否合理？

**没有用户确认，不要进入 Phase 3。**

## 退出条件

- [ ] MISSION.md 已完成
- [ ] 3-5 条验收标准，条条可验证
- [ ] 范围明确（含 out of scope）
- [ ] 用户确认项目目标
