# Phase 1：绘制能力地图

## 触发条件

Phase 0 完成。

## 流程

### 1. AI 初始化 RESOURCES.md

按 `formats/templates.md` 中 RESOURCES.md 格式填充：
- 至少 1 个官方文档来源
- 至少 1 个安装/环境搭建来源
- 至少 1 个排障/社区来源
- 固定版本号（如适用）

### 2. AI 初始化 LEARNING_MAP.md（能力地图）

按 `formats/templates.md` 中 LEARNING_MAP.md 格式创建骨架：

**按"解决工程问题所需能力"组织，不照抄教材目录。** 教材目录只作参考索引，不作学习顺序。

- **能力维度区**：列出完成项目所需的核心能力。Python 主题直接用 `references/python-skeleton.md` 的十项能力树（数据与控制 / 函数与模块 / 文件与配置 / HTTP与API / 错误与调试 / 数据模型与状态 / 测试 / 数据库 / Web开发 / 部署与工程化）
  - 每项能力只保留：当前掌握等级（默认 L0，用户见过/用过则 L1+）、对应实践项目、下一步任务
  - 详细知识不放地图
- **核心模块区**：知识层面的模块拆解（每个 ≤ 60 分钟），标注 in scope / out of scope 和前置依赖
- 标注哪些能力 out of scope（本次学习不碰）

### 3. 确认目标等级

与用户确认本次学习的能力目标等级：

| 目标等级 | 任务形式 |
|----------|----------|
| L1 | 解释和识别练习 |
| L2 | 借助 AI 局部修改并验证 |
| L3 | 从需求出发，借助 AI 可靠交付并掌握验收权 |
| L4 | 在新场景或约束下借助 AI 再次交付，比较方案并解释取舍 |

后续每条 todo 的目标等级不高于对应能力当前等级 + 1（禁止从 L0 直接跳到 L4）。

### 4. AI 初始化 GLOSSARY.md

填入核心术语及其空结构（后续逐步填充定义）。

### 5. 用户可选：用 XMind 画图

- 用户可以在 XMind 里画能力骨架帮助思考
- **但 LEARNING_MAP.md 是机器可读的权威版本**
- AI 根据用户 XMind 同步更新 LEARNING_MAP.md（如有遗漏能力维度则补充）

### 检查完整性

与用户确认：
- 能力维度是否有遗漏
- 目标等级是否合理
- 核心模块划分是否合理
- Out of scope 是否正确

## 退出条件

- [ ] RESOURCES.md 已初始化（含版本信息）
- [ ] LEARNING_MAP.md 已创建：能力维度（含等级）+ 核心模块，确认无遗漏
- [ ] 目标等级已确认
- [ ] GLOSSARY.md 已初始化
- [ ] 用户确认地图完整
