# Phase 4：费曼检验

## 触发条件

- 核心模块完成时自动触发
- 用户主动要求"考考我"

## 流程

### 1. 触发

> "给我讲一遍这个模块，我装不懂追问。"

### 2. 评判

**讲清了 →** 写入 learning-record（模板见 `formats/templates.md`）：
- evidence_type: feynman
- status: active
- Evidence: 能解释给 AI 并答追问

**卡壳了 →** 写入 learning-record：
- status: weak-spot
- 记录具体哪里说不清

### 3. 后续

| 结果 | 动作 |
|------|------|
| 讲清了 | 可以学下一个模块 |
| 卡壳了 | 先补薄弱点，重新费曼，再继续 |
| 部分讲清 | 标记模糊部分为 weak-spot，继续但排障时重点考察 |

## 规则

**不要替用户总结。** 让用户自己讲，AI 只追问。
**追问要真实。** 不是走过场，要针对易混淆点深挖。
**卡壳不要直接给答案。** 先引导："你再想想 X 部分？"
